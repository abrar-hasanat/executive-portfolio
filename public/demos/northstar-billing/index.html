Read the latest invoice and event history from your Supabase project. This dashboard cannot change billing records.

One-time setup
  1. Download the read-only access SQL and run it in Supabase SQL Editor.
  2. In Supabase Authentication → Users, create a user with the approved email below and a new password. Confirm the user’s email.
  3. Copy your project's publishable key from Settings → API Keys.
  4. Enter the key and that project user's login below, then connect.
The SQL approves hasanata@carleton.edu. Change that email in the SQL if you use a different one. Your Supabase account login is separate from this project's Auth user.

Use a project Auth user password. Never enter a database password, service-role key, or Metronome token. Passwords and session tokens are not saved by this app.
